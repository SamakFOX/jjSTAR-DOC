온라인상담 UI 한눈에보기

< 온라인상담 UI >

1
상담자 지정 : 상담을 받아주실 단대/학과 소속 상담자를 선택하는 곳이에요
2
상담 상세정보 : 상담 조건을 설정하고 상담 요청을 등록하는 곳이에요
3
상담 이력 : 이전에 신청한 상담 목록과 상태를 확인하는 곳이에요

예시) 제이제이가 교수님의 진도를 따라가기 위해 상담을 신청하려고 해요

STEP 1
내 학과에 계시는 제이트 교수님을 선택해요
STEP 2
상담일자 / 유형 / 상담 내용을 입력하고 상담예약신청 버튼 클릭
STEP 3
상담 이력에서 상담 확정 여부를 확인하고 해당 날짜에 방문해요
Note

※ 상담 내용은 자세히 입력할수록 상담 결과가 만족스러워요!
