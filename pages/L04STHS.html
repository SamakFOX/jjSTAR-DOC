starT 신청 현황 바로가기

starT 신청 현황 UI 한눈에 보기

신청한 활동과 인증일자, 진행상태와 취소사유를 살펴봐요

1
신청내역
프로그램과 구분, 활동사항과 인증일자를 확인하는 영역이에요
2
진행상태와 사유
신청·승인·미승인·임시저장 등 활동별 진행상태를 확인해요
취소사유에 안내된 내용이 있다면 함께 읽어봐요
3
수정·취소
기능 열에 [수정]과 [취소]가 표시된 활동에서 해당 항목을 이용할 수 있어요

* 같은 활동이라도 진행상태에 따라 수정·취소 항목이 다르게 표시될 수 있어요

활동사항과 상태를 먼저 확인하고 변경할 신청의 버튼을 눌러요

신청한 활동 수정·취소하기

STEP 1
신청내용과 진행상태 확인하기

상단의 [조회]를 누르고 프로그램과 구분, 활동사항을 확인해요

진행상태와 취소사유를 읽고 수정하거나 취소할 활동을 찾아요

STEP 2
신청내용 수정하기

해당 활동의 [수정]을 누르고 활동기간과 활동내용, 비고를 확인해요

바꿀 내용을 적은 뒤 [다음]을 눌러 첨부파일을 확인해요

[신청]을 누르고 확인 창에서 [예]를 선택해 변경내용을 반영해요
완료 안내를 확인한 뒤 목록을 다시 조회해 신청내용을 살펴봐요

STEP 3
신청 취소하기

취소할 활동의 [취소]를 누르고 확인 창에서 [예]를 선택해요

취소 완료 안내를 확인한 뒤 목록을 다시 조회해 남은 신청내역을 확인해요
