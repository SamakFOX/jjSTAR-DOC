가이드 이미지 교체 방법

1. outputs/guide-images-20261018/가이드_이미지_작업표.xlsx에서 이미지 번호와 촬영할 내용을 확인합니다.
2. 엑셀의 저장 경로에 적힌 이름으로 실제 WebP 파일을 내보냅니다.
3. assets/images의 같은 이름 파일을 덮어씁니다. HTML 수정은 필요 없습니다.
4. 가이드 화면을 새로고침합니다. 이전 그림이 남으면 Ctrl+F5로 강력 새로고침합니다.

레벨4 상세 이미지의 기존 규칙
- L04 접두어를 제외하고 나머지 메뉴코드를 소문자로 사용합니다.
- 메인 화면: jjstar_d_<메뉴코드>-main.webp
- 예시/단계 화면: jjstar_d_<메뉴코드>-ex-01.webp, -ex-02.webp, ...
- 예: L04SCHQ → jjstar_d_schq-main.webp

레벨2·3의 기존 대표 이미지 이름은 유지합니다.
이미지 번호 IMG-xxx는 엑셀과 화면의 위치를 찾기 위한 식별자이며 파일명은 아닙니다.
파일 확장자만 바꾸지 말고 WebP 형식으로 내보내세요.
번호가 들어간 임시 그림은 실제 이미지로 교체하면 사라집니다.
권장 크기보다 원래 화면 비율과 글자 가독성을 우선합니다.
기간·권한 제한은 엑셀의 촬영조건을 확인하고 개인정보는 가려서 작업합니다.
