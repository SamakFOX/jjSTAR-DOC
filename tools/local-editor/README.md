# 로컬 가이드 문구 편집기

## 실행

VS Code 터미널을 **PowerShell**로 열고 프로젝트 최상단에서 실행해요

```powershell
python tools/local-editor/server.py --port 8765
```

이미 8765번 서버가 실행 중이면 그 서버의 터미널에서 `Ctrl+C`로 종료한 뒤 실행해요

- 일반 프리뷰: <http://127.0.0.1:8765/index.html>
- 문구 편집기: <http://127.0.0.1:8765/__editor/>

일반 프리뷰에서 원하는 메뉴를 연 뒤 오른쪽 아래 **문구 편집**을 누르면 해당 문서의 편집기가 열려요

저장 기능은 이 로컬 서버에서만 작동해요. 기존 `python -m http.server`나 GitHub Pages에서는 편집 버튼이 추가되지 않아요

## 사용 순서

1. 상단 검색창에 메뉴명이나 코드를 입력하고 문서를 선택해요
2. 프리뷰의 제목·설명·이미지 캡션 등 문구를 클릭해 수정해요
3. 서식을 바꾸려면 **같은 문단 안의 문구를 드래그**하고 상단의 서식 버튼을 눌러요
4. **변경 확인·저장** 또는 `Ctrl+S`를 눌러 변경 전후 문구와 저장 위치를 확인해요
5. **원본 파일에 저장**을 누르면 저장돼요
6. 일반 프리뷰를 새로고침한 뒤 메뉴를 다시 열어 최종 화면을 확인해요

자동 저장은 하지 않아요. 수정한 문구에는 노란 점선이 표시되고, 상태줄에 미저장 문구 수가 나와요

## 서식

| 서식 | 적용 결과 |
|---|---|
| 일반 텍스트 | 선택한 문구의 버튼·색상·굵기 등 서식을 제거 |
| 일반 버튼 | 회색 버튼 모양 |
| JJSTAR 버튼 | 파랑 `#0083c3`·회색 `#c8cbd0`, hover 시 노랑 `#f3d02a`·검정 `#1d1d1d` |
| ★ 영역 제목 | `assets/icons/icon-star-01.webp`와 굵은 글씨 |
| 굵게 | 굵은 글씨 |
| 파랑·빨강·노랑 강조 | 해당 색상의 굵은 글씨 |

서식은 선택한 문구에 교체 적용돼요. 링크 문구에 버튼·일반 텍스트 서식을 적용하면 선택한 부분의 링크도 제거되므로, 기존 링크를 유지하려면 해당 부분을 선택에서 제외해 주세요

- `Enter`: 같은 문단 안에서 줄바꿈
- `Ctrl+Z` / `Ctrl+Y`: 편집기 내 되돌리기 / 다시 실행
- `Ctrl+B`: 선택한 문구를 굵게
- 붙여넣기: 외부 서식을 제외한 텍스트만 입력
- 다크 화면: 어두운 테마에서 문구 모양 확인

## 저장 위치와 충돌 처리

- 본문 문구는 해당 `pages/*.html` 파일의 변경한 부분만 교체해요
- 상단 소개 문구가 `data/strings.js`에서 공급되면 그 파일의 해당 `desc`만 수정해요
- 저장 전에 두 파일의 변경 여부를 확인해요. VS Code나 다른 편집기에서 변경됐다면 저장을 차단해요
- 충돌 시 편집 중인 문구를 복사해 보관하고 **다시 불러오기** 후 재적용해요
- 자동 백업은 `outputs/local-editor-backups/저장시각/` 아래에 원래 폴더 구조대로 남아요
- 편집기의 되돌리기는 저장 전 편집 이력에만 적용돼요. 저장한 내용을 되돌리려면 백업과 원본을 비교해 필요한 문구를 복구해요

## 편집 범위

본문의 문구·소제목·이미지 설명을 편집해요. 메뉴명, 자동 생성 메뉴 목록, 이미지 파일·배치, 스크립트로 생성되는 내용은 기존 코드나 설정에서 관리해요

대분류·중분류 페이지는 원본 문서에 있는 문구를 표시해요. 실제 사이트에서 자동으로 생성하거나 임베드하는 목록 전체를 편집하는 화면은 아니에요. 임베드된 상세 안내를 수정할 때는 해당 원본 문서를 선택해요

문구 편집 버튼과 편집 속성은 서버가 로컬 화면에만 추가하며 원본 가이드에는 저장하지 않아요
