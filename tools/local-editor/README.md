# 로컬 가이드 편집기

## 실행

VS Code 터미널을 **PowerShell**로 열고 프로젝트 최상단에서 실행해요

```powershell
python tools/local-editor/server.py --port 8765
```

이미 8765번 서버가 실행 중이면 그 서버의 터미널에서 `Ctrl+C`로 종료한 뒤 실행해요

- 일반 프리뷰: <http://127.0.0.1:8765/index.html>
- 가이드 편집기: <http://127.0.0.1:8765/__editor/>

일반 프리뷰에서 원하는 메뉴를 연 뒤 오른쪽 아래 **문구 편집**을 누르면 해당 문서의 편집기가 열려요

저장 기능은 이 로컬 서버에서만 작동해요. 기존 `python -m http.server`나 GitHub Pages에서는 편집 버튼이 추가되지 않아요

## 사용 순서

1. 상단 검색창에 메뉴명이나 코드를 입력하고 문서를 선택해요
2. 프리뷰의 제목·설명·이미지 캡션 등 문구를 클릭해 수정해요
3. 서식을 바꾸려면 **같은 문단 안의 문구를 드래그**하고 상단의 서식 버튼을 눌러요
4. **변경 확인·저장** 또는 `Ctrl+S`를 눌러 변경 전후 문구와 저장 위치를 확인해요
5. **원본 파일에 저장**을 누르면 저장돼요
6. 일반 프리뷰를 새로고침한 뒤 메뉴를 다시 열어 최종 화면을 확인해요

자동 저장은 하지 않아요 상태줄에 저장하지 않은 변경 내용이 표시돼요

## 화면과 코드 전환

1. 상단 도구 모음에서 **다크 화면** 왼쪽의 **코드로 보기**를 눌러요
2. 현재 편집 중인 본문 HTML을 확인하거나 복사해요
3. **화면으로 보기**를 누르면 편집하던 화면으로 돌아와요

코드 화면은 읽기 전용이에요 저장하지 않은 문구와 구성 변경도 코드에 표시되며, 화면을 전환해도 편집 내용과 되돌리기 이력이 유지돼요 코드에는 편집기의 선택 표시나 임시 속성을 제외한 작업본 HTML이 표시돼요

## 섹션과 구성 추가·삭제

왼쪽 **문서 구성** 목록에서 섹션이나 그 안의 항목을 선택해요 본문의 항목을 클릭해서 선택할 수도 있어요

1. **구성 추가**에서 섹션·소제목·본문 문단·이미지 홀더·캐릭터 팁박스·STEP 안내·구분선 중 하나를 골라요
2. 선택 항목 앞·뒤 또는 선택 영역 안 중 추가할 위치를 골라요
3. **선택한 구성 추가**를 누른 뒤 본문에서 제목과 설명을 수정해요
4. **선택한 구성**의 위로·아래로·복제·삭제 버튼으로 구성을 정리해요
5. **변경 확인·저장 → 원본 파일에 저장**으로 반영해요

저장 전에는 `Ctrl+Z`로 추가·삭제·순서 변경까지 되돌릴 수 있어요 연결용 ID가 있는 항목과 메뉴에서 관리하는 상단 영역은 삭제나 이동이 제한돼요 탭 바로가기 등 기존 연결을 유지하기 위한 제한이에요

### 문서 구성 접고 펼치기

왼쪽 **문서 구성**은 본문의 묶음과 그 안의 항목을 계층으로 보여줘요 항목 왼쪽의 화살표를 누르면 하위 항목을 접거나 펼칠 수 있어요 접기와 펼치기는 원본 문서에 저장되지 않아요

이미지와 하단 설명은 **이미지 묶음**으로 표시돼요 묶음을 펼치면 이미지와 캡션을 각각 선택할 수 있어요 캡션 문구는 본문에서 수정하고, 이미지 파일명과 대체 설명은 **이미지 파일명·설명**에서 설정해요

### 본문에서 상위 묶음 선택하기

1. 본문에서 문단이나 이미지를 클릭해요
2. 선택한 항목 옆의 **↑ 상위 묶음**을 누르면 한 단계 위 묶음 전체가 선택돼요
3. 편집 영역 상단의 **선택 경로**에서도 해당 항목을 감싸는 묶음을 확인하고 버튼을 눌러 선택할 수 있어요

선택 경로는 본문의 실제 구조를 따라 표시돼요 문단부터 STEP·행·이미지 묶음까지 원하는 범위를 선택한 뒤 함께 이동하거나 복제할 수 있어요 묶음의 빈 공간을 클릭해서 선택할 수도 있어요 경로로 범위를 바꿔도 보고 있던 스크롤 위치는 유지돼요

### 순서 변경

1. **문서 구성**에서 옮길 문단·이미지 묶음·STEP 등을 선택해요
2. 항목을 끌어 원하는 앞뒤 위치의 삽입선에 놓아요 또는 **위로·아래로** 버튼을 눌러 한 칸씩 이동해요
3. 프리뷰에서 순서를 확인하고 **변경 확인·저장 → 원본 파일에 저장**을 눌러요

같은 부모 영역 안의 항목끼리 순서를 바꿀 수 있어요 이미지와 캡션은 묶음 단위로 함께 이동해요 상단 제목과 자동 목록 등 고정 영역은 유지하며, 다른 섹션 안으로 옮기는 동작은 제한돼요

이번 편집에서 GAP을 추가하거나 문단을 팁박스로 바꾼 영역은 먼저 저장한 뒤 안쪽 항목의 순서를 바꿔요 저장 전에는 영역 전체만 함께 이동할 수 있어요

### 여러 항목 함께 이동하기

1. 본문이나 왼쪽 **문서 구성**에서 첫 항목을 선택해요
2. `Ctrl`을 누른 채 다른 항목을 클릭하면 선택에 추가하거나 뺄 수 있어요 Mac에서는 `Cmd`를 사용해요 왼쪽 목록의 체크박스로도 선택할 수 있어요
3. 첫 항목을 선택한 뒤 `Shift`를 누르고 마지막 항목을 클릭하면 같은 부모 안의 범위를 선택해요
4. 선택한 항목의 손잡이를 끌거나 **위로·아래로**를 누르면 선택한 항목들이 본문 순서대로 함께 이동해요

다른 부모 영역의 항목이나 상위 묶음과 그 안의 항목을 섞어서 선택할 수 없어요 이미지와 캡션은 한 묶음으로 선택해요 함께 이동한 내용은 **되돌리기** 한 번으로 이전 순서로 돌아갈 수 있어요

한 묶음 안의 모든 항목을 선택하면 이동할 수 있는 형제 묶음이 있을 때 그 묶음 전체를 함께 옮길 수 있어요 이동 후에도 각 항목의 선택과 선택 개수는 유지돼요

여러 항목을 선택한 동안에는 문구·서식·GAP·팁박스·이미지 설정과 구성 추가·삭제·복제가 잠겨요 문구를 수정하려면 원하는 항목만 다시 클릭해 한 개를 선택해요 **선택 해제**로 전체 선택을 풀 수도 있어요

### 본문에서 끌어 이동하기

1. 본문에서 옮길 문단·이미지 묶음·STEP 등을 클릭해 선택해요
2. 선택한 블록 옆의 드래그 손잡이를 잡고 이동해요
3. 원하는 앞뒤 위치에 표시되는 파란 삽입선을 확인한 뒤 놓아요

손잡이를 잡을 때 구성 이동이 시작돼요 본문의 글자를 드래그하면 문구를 선택할 수 있어요 이동 가능한 범위와 이미지·캡션 묶음, GAP·팁박스의 제한은 왼쪽 목록과 같아요

`Esc`를 누르거나 놓을 수 있는 위치 밖에 놓으면 이동을 취소해요 이동한 뒤에는 **되돌리기** 또는 `Ctrl+Z`로 이전 순서로 돌아갈 수 있어요 코드 보기로 전환해도 현재 순서와 되돌리기 이력은 유지돼요

## 이미지 홀더와 파일명 설정

1. 추가할 내용을 **이미지 홀더**로 선택하고 1장·2장 나란히·3장 나란히 중 배치를 골라요
2. 이미지를 더블클릭하거나 이미지를 선택한 뒤 **이미지 파일명·설명**을 눌러 설정 창을 열어요 기존 이미지도 같은 방법으로 수정할 수 있어요
3. 이미지 파일명, 대체 설명, 이미지 아래 캡션을 입력해요 폴더에 있는 파일명은 입력 중 목록에서 선택할 수 있어요
4. **적용**으로 프리뷰를 확인한 뒤 원본 파일에 저장해요

파일명은 `assets/images` 폴더를 기준으로 입력해요 예를 들어 `jjstar_d_tgjb-ex-01.webp`를 입력하면 `assets/images/jjstar_d_tgjb-ex-01.webp`에 연결돼요

아직 없는 파일명도 먼저 설정할 수 있어요 같은 이름의 파일을 `assets/images`에 넣으면 표시돼요 이 설정은 이미지 연결 정보만 저장하며, 이미지 파일의 업로드·이름 변경·삭제는 하지 않아요

## 서식

| 서식 | 적용 결과 |
|---|---|
| 일반 텍스트 | 선택한 문구의 버튼·색상·굵기 등 서식을 제거 |
| 일반 버튼 | 회색 버튼 모양 |
| JJSTAR 버튼 | 파랑 `#0083c3`·흰색 `#ffffff`, hover 시 노랑 `#f3d02a`·검정 `#1d1d1d` |
| ★ 영역 제목 | `assets/icons/icon-star-01.webp`와 굵은 글씨 |
| 시그니처 제목 | `assets/images/jjstar-head-title.svg` 아이콘과 큰 제목 글씨 |
| 굵게 | 굵은 글씨 |
| 파랑·빨강·노랑 강조 | 해당 색상의 굵은 글씨 |

서식은 선택한 문구에 교체 적용돼요. 링크 문구에 버튼·일반 텍스트 서식을 적용하면 선택한 부분의 링크도 제거되므로, 기존 링크를 유지하려면 해당 부분을 선택에서 제외해 주세요

### 문단을 팁박스로 바꾸기

1. 바꾸려는 본문 문단 안을 클릭해요. 문구를 드래그할 필요는 없어요
2. **팁박스로 전환**을 누르면 문단 전체에 기존 캐릭터 팁박스 디자인이 적용돼요
3. 같은 버튼을 다시 누르면 저장 전 전환을 취소해요. 되돌리기·다시 실행도 사용할 수 있어요
4. **변경 확인·저장 → 원본 파일에 저장**을 누르면 팁박스 구조까지 저장돼요

문구·강조·링크는 그대로 유지해요. 제목·상단 소개·기존 팁박스와 표나 가로 배치 안의 문구는 전환하지 않아요. 여러 문단을 한꺼번에 묶는 기능은 아니에요

### 내용 사이에 GAP 넣기

1. 간격을 띄울 기준 문단이나 소제목을 클릭해요
2. **GAP 앞** 또는 **GAP 뒤**를 누르면 해당 문단 바깥에 여백이 생겨요
3. 편집 화면에서 추가 GAP은 노란 점선으로 표시돼요. 저장한 가이드에서는 빈 여백으로 표시돼요
4. **추가 GAP 취소**는 선택한 문단에 이번 편집에서 추가한 GAP을 제거해요. 되돌리기도 사용할 수 있어요

여백은 기존 `guide-spacer-v` 스타일을 사용해요(현재 70px). 앞뒤 각각 3개까지 추가할 수 있고, 공통 스타일을 바꾸면 여백 크기도 함께 바뀌어요. 이미 저장되어 있던 GAP은 이 버튼으로 제거하지 않아요

### 선택한 항목 앞뒤 여백 조절하기

1. 문단이나 이미지 묶음을 선택해요
2. 왼쪽 **선택한 구성 → 선택 앞·뒤 여백**에서 크기를 골라요 0·8·12·16·24·32·48·70px 중 선택할 수 있어요
3. **앞 여백** 또는 **뒤 여백**을 눌러 선택한 항목 바깥의 간격을 조절해요 여러 항목을 선택했다면 첫 항목 앞이나 마지막 항목 뒤에 적용돼요
4. 인접한 여백 블록을 없애려면 **여백 제거**를 눌러요 0px을 골라 해당 방향의 여백을 제거할 수도 있어요

가로·격자 배치 안의 항목은 묶음 전체를 선택해 바깥 간격을 조절해요 이미지와 캡션 사이의 간격은 묶음 안에 유지돼요 여백 변경도 저장 전에 되돌릴 수 있어요

### 이동 후 간격 자동보정

항목을 옮기면 이동한 본문 오른쪽에 **간격 자동보정**이 10초 동안 표시돼요 버튼을 누르면 방금 이동한 항목과 이웃한 이미지·문구 사이에서 12px 미만으로 좁은 경계에 24px 여백을 보완해요

보정은 버튼을 눌렀을 때 적용돼요 충분한 여백과 가로·격자 배치는 유지돼요 보정한 간격도 **되돌리기**로 취소할 수 있어요

시그니처 제목은 제목으로 쓸 문구를 드래그하고 적용해요. 기존 아이콘 제목 행에서는 아이콘을 중복으로 넣지 않아요

- `Enter`: 같은 문단 안에서 줄바꿈
- `Ctrl+Z` / `Ctrl+Y`: 편집기 내 되돌리기 / 다시 실행
- `Ctrl+B`: 선택한 문구를 굵게
- 붙여넣기: 외부 서식을 제외한 텍스트만 입력
- 다크 화면: 어두운 테마에서 문구 모양 확인

## 저장 위치와 충돌 처리

- 본문 문구와 섹션·이미지 구성은 해당 `pages/*.html` 파일에 저장해요 구조를 바꾸지 않은 영역은 원래 코드를 유지해요
- 상단 소개 문구가 `data/strings.js`에서 공급되면 그 파일의 해당 `desc`만 수정해요
- 저장 전에 두 파일의 변경 여부를 확인해요. VS Code나 다른 편집기에서 변경됐다면 저장을 차단해요
- 충돌 시 편집 중인 문구를 복사해 보관하고 **다시 불러오기** 후 재적용해요
- 자동 백업은 `outputs/local-editor-backups/저장시각/` 아래에 원래 폴더 구조대로 남아요
- 편집기의 되돌리기는 저장 전 편집 이력에만 적용돼요. 저장한 내용을 되돌리려면 백업과 원본을 비교해 필요한 문구를 복구해요

### 저장 중 오류가 날 때

- 서버를 다시 실행한 뒤 오래 열린 편집 창에서 저장 권한이 만료되면 연결 정보를 새로 받아 한 번 다시 저장해요
- 파일 쓰기 권한이 거부되면 원본 파일과 `outputs/local-editor-backups` 폴더의 읽기 전용 설정, 다른 프로그램의 파일 잠금을 확인해요. 입력한 문구는 편집 화면에 남아요
- 파일 변경 충돌 안내가 나오면 편집한 문구를 복사해 두고 **다시 불러오기** 후 적용해요. 다른 창에서 바꾼 내용을 덮어쓰지 않아요
- **저장 완료** 뒤 미리보기 갱신 안내가 나오면 원본 저장은 끝난 상태예요. 저장을 반복하기보다 일반 프리뷰를 새로고침해 확인해요

## 편집 범위

본문의 문구·소제목·섹션·팁박스·STEP·이미지 배치와 설명을 편집해요 메뉴명, 자동 생성 메뉴 목록, 스크립트로 생성되는 내용은 기존 코드나 설정에서 관리해요

대분류·중분류 페이지는 원본 문서에 있는 문구를 표시해요 실제 사이트에서 자동으로 생성하거나 임베드하는 목록 전체를 편집하는 화면은 아니에요 임베드된 상세 안내를 수정할 때는 해당 원본 문서를 선택해요 여러 개의 독립 영역으로 구성된 초기 홈 문서는 문구 편집만 지원해요

문구 편집 버튼과 편집 속성은 서버가 로컬 화면에만 추가하며 원본 가이드에는 저장하지 않아요
